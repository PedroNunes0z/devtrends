Rotas e cotas. O que cada consulta custa.

O GitHub permite 60 requisições por hora sem token e 5.000 com token. A Stack Exchange API aceita 300 por dia sem chave. Nada roda em servidor: tudo é chamado pelo seu navegador.

Perguntas frequentes. Inclusive sobre o que não é real.

O que é o Índice de Vitalidade?
Uma nota de 0 a 100 que combina popularidade no GitHub (estrelas, forks, atividade recente) com suporte da comunidade no Stack Overflow (volume de dúvidas e taxa de perguntas sem resposta). O Gemini interpreta os dados e devolve a nota, a tendência e as tags de saúde.
De onde vêm os dados?
Da GitHub REST API, da Stack Exchange API e, quando você roda tools/scraper.mjs localmente, de scraping da página de perguntas do Stack Overflow. Cada widget exibe a origem e avisa quando um dado é estimado.
O histórico do gráfico é real?
O ponto final de cada série é o valor real atual. A curva histórica é modelada a partir desse total, da idade do repositório e da velocidade real dos últimos stargazers. O gráfico identifica o que é estimativa.
Preciso de chaves de API?
Não. GitHub e Stack Overflow funcionam nas cotas públicas. Sem chave Gemini o relatório usa uma heurística local determinística, sinalizada na interface. As chaves ficam apenas no localStorage do seu navegador.
