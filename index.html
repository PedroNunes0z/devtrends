README

Um relatório completo. Gerado quando você clica em Analisar.

Nada está pré-computado aqui: cada análise é uma chamada real das APIs na hora do clique. Foco, profundidade e perfil vão para o Gemini junto com os dados.

2.0 Análise →

Opções de análise (enviadas ao Gemini)

Em Três chamadas. Nenhum número inventado no caminho.

Cada etapa expõe o comando que a executa. Os contêineres ficam empilhados, um abaixo do outro, na ordem do pipeline.

1.0 Pipeline →

01 · github.js

Repositório principal, estrelas, forks, issues e amostragem real dos últimos stargazers.

02 · stackoverflow.js

Totais e amostra de perguntas recentes da tag. Em localhost, o scraper próprio (tools/scraper.mjs) raspa o DEV.TO (home, trending e busca); no Pages, as APIs públicas do dev.to e do Hacker News assumem.

03 · gemini.js

Structured output: nota, tendência, justificativa e tags com tipos garantidos por responseSchema.

Veja em ação. Da busca ao relatório rendered em widgets.

Gravação real do aplicativo: a busca por uma tecnologia, as opções de análise e o relatório construído a partir das chamadas das APIs.

Perguntas frequentes. Inclusive sobre o que não é real.

O que é o Índice de Vitalidade?
Uma nota de 0 a 100 que combina popularidade no GitHub (estrelas, forks, atividade recente) com suporte da comunidade no Stack Overflow (volume de dúvidas e taxa de perguntas sem resposta). O Gemini interpreta os dados e devolve a nota, a tendência e as tags de saúde.
De onde vêm os dados?
Da GitHub REST API, da Stack Exchange API e, quando você roda tools/scraper.mjs localmente, de scraping do DEV.TO (home, trending e busca por tag). O buzz no Hacker News vem da API pública de busca (Algolia), com CORS liberado, em qualquer ambiente. Cada widget exibe a origem e avisa quando um dado é estimado.
O histórico do gráfico é real?
O ponto final de cada série é o valor real atual. A curva histórica é modelada a partir desse total, da idade do repositório e da velocidade real dos últimos stargazers. O gráfico identifica o que é estimativa.
Preciso de chaves de API?
Não. GitHub e Stack Overflow funcionam nas cotas públicas. Sem chave Gemini o relatório usa uma heurística local determinística, sinalizada na interface. As chaves ficam apenas no localStorage do seu navegador.
